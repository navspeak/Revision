# NLP — Foundations Module

Natural Language Processing — making machines understand, interpret, and generate human language.

This module covers the **foundations** — preprocessing, lexical processing, morphology, syntax, and the basics of statistical NLP. Modern deep learning techniques (Transformers, BERT, GPT) build on these foundations and are covered in separate modules.

## Key Concepts to Remember

```
Lexical level    → words: normalisation, tokenisation, stopwords, stemming
Morphological    → word structure: prefixes, suffixes, roots
Syntactic        → sentence structure: POS tagging, parsing, grammar
Semantic         → meaning (covered in advanced modules)
Pragmatic        → context and intent (covered in advanced modules)
```

The foundations module focuses primarily on **lexical, morphological, and syntactic** processing.
