# M2 — Exploratory Data Analysis (EDA)

EDA is the process of understanding a dataset's structure, patterns, and relationships using summary statistics and visual methods — before modelling.

---

## Module Agenda

| # | Topic | Key Ideas |
|---|-------|-----------|
| 1 | Descriptive Statistics | Mean, median, mode, range, variance, SD, percentiles, quartiles, histograms, box plots |
| 2 | Univariate Analysis | Distribution of individual variables (numerical + categorical), histograms, outliers |
| 3 | Segmented Univariate Analysis | Compare distributions across subgroups (e.g. avg cost by country) |
| 4 | Bivariate Analysis | Relationships between two variables — scatter plots, correlation, cross-tabs |
| 5 | Derived Metrics | New variables built from existing ones using business logic or analytical goals |

---

## Learning Outcomes

- Summarise datasets using descriptive statistics in Python
- Explore individual variable behaviour (univariate)
- Compare metrics across groups (segmented analysis)
- Examine variable relationships (bivariate)
- Engineer new features / metrics from raw data
- Use visual tools: histograms, box plots, scatter plots, violin plots
- Interpret findings into business conclusions
