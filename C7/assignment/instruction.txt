Welcome to the assignment on transfer learning!

Problem Statement
 
Objective
The objective of this assignment is to identify surface defects in industrial materials using transfer learning with convolutional neural networks. Learners will use a pre-trained deep learning model and adapt it to classify surface defects from image data by appropriately loading the model, configuring a freezing strategy, and retraining it on the target dataset.

 

The problem statement for this assignment can be summarised as follows:

“Given images of industrial surfaces belonging to different defect categories, use a pre-trained convolutional neural network to correctly classify the defect type.”

 
Business Value
In industrial manufacturing, surface defects directly affect product quality, safety, and customer satisfaction. Manual inspection is time-consuming, expensive, and prone to human error, especially at scale. Computer vision–based defect identification systems enable:

faster inspection pipelines

consistent quality control

early detection of production issues

 

However, collecting large labelled datasets for every new manufacturing setting is often impractical. Transfer learning addresses this challenge by reusing visual representations learned from large-scale datasets and adapting them efficiently to domain-specific inspection tasks.

 

 

Dataset Overview
 

Context
The dataset consists of images representing different types of surface defects commonly observed in industrial materials. Each image belongs to exactly one defect category. The dataset is already organised into class-wise folders and is suitable for supervised image classification.

 

Content
The dataset contains multiple defect classes - crazing, inclusion, patches, pitted surfaces, rolled-in scale, and scratches

Images are grayscale

The training and validation sets are already split into two subfolders in the data

Both the training and validation data contain an "image" folder and an "annotations" folder

The "images" folder has subdirectories, each containing images for a specific defect class

The dataset is pre-cleaned and does not contain missing labels

 

Image Folders

The dataset is organised in a directory-based structure suitable for supervised image classification. Each defect category is stored in a separate folder. A typical directory structure (train folder, for example) is shown below:

NEU-DET/train/
│
└─ images/
         │
         ├── crazing/
         │      ├── crazing_1.jpg
         │      └── ...
         │
         ├── inclusion/
         │
         ├── patches/
         │
         ├── pitted_surface/
         │
         ├── rolled-in_scale/
         │
         └── scratches/
 

 
Each folder represents one defect class

All images within a folder belong to the same class

The dataset has a uniform class distribution, making accuracy an appropriate evaluation metric

Image size: 200 × 200 pixels

Number of channels: 1 (grayscale)

 


For this assignment, you are not required to parse or use the annotation files. The bounding box information is provided for dataset completeness and future extensions (e.g. object detection tasks). You can use the directory names for class labels.
