  ---                                                                                                                                                                                                 
  How to read it:                                                                                                                                                                                       
                                                                                                                                                                                                      
  - Row = first decimal of Z (e.g. 1.9)
  - Column = second decimal of Z (e.g. .06)                                                                                                                                                             
  - Cell value = F(z) = P(Z ≤ z) = area to the left
                                                                                                                                                                                                        
  Example — find F(1.96):                                                                                                                                                                               
  1. Go to row 1.9                                                                                                                                                                                      
  2. Go to column .06                                                                                                                                                                                   
  3. Read cell → 0.9750                                                                                                                                                                               
                       
  So P(Z ≤ 1.96) = 0.9750 = 97.5%                                                                                                                                                                       
                                                                                                                                                                                                        
  ---                                                                                                                                                                                                   
  For negative Z — use symmetry:                                                                                                                                                                        
  F(-1.96) = 1 - F(1.96) = 1 - 0.9750 = 0.0250        


  
If the variable is normally distributed, and even if you do not know the values of µ and σ,
 you can calculate the value of P(X < µ + σ) using the empirical rule and the symmetric property of the normal distribution. 
 Here, P(X < µ + σ) = P(X < µ) + P(µ < X < µ + σ) = 0.5 + 0.68/2 = 0.5 + 0.34 = 0.84 = 84%. 
 Hence, irrespective of the values of µ and σ, P(X < µ + σ) for a normal distribution will always be 84%.

 Look at Z table z=1.0 


 ==========
What is the probability of a normally distributed random variable lying within 1.65 standard deviations of the mean? 
90%

P(-1.65<X<1.65) = Z table at 1.65 - at -1.65 = 0.95 - 0.049

F(1.65)  = 0.9505                                                                                                                                                                                     
  F(-1.65) = 0.0495   ← from negative Z table (or 1 - 0.9505)
                                                                                                                                                                                                        
  P(-1.65 < Z < 1.65) = F(1.65) - F(-1.65)                                                                                                                                                              
                      = 0.9505 - 0.0495                                                                                                                                                                 
                      = 0.9010                                                                                                                                                                          
                      ≈ 90% ✓                               
                                                                                                                                                                                                        
  Symmetry shortcut — since normal is symmetric:                                                                                                                                                        
                                                                                                                                                                                                        
  P(-1.65 < Z < 1.65) = 2 × F(1.65) - 1                                                                                                                                                                 
                      = 2 × 0.9505 - 1                      
                      = 0.9010
                                                                                                                                                                                                        
  So Z = ±1.65 is the value that captures exactly 90% of the distribution — useful to memorise alongside 1.96 (95%) and 2.576 (99%).
