● ax² + bx + c = 0

  x = (-b ± √(b² - 4ac)) / 2a

  Three cases based on discriminant (b² - 4ac):

  ┌──────────────┬─────────────────────────┐
  │ Discriminant │          Roots          │
  ├──────────────┼─────────────────────────┤
  │ > 0          │ Two distinct real roots │
  ├──────────────┼─────────────────────────┤
  │ = 0          │ One repeated real root  │
  ├──────────────┼─────────────────────────┤
  │ < 0          │ Two complex roots       │
  └──────────────┴─────────────────────────┘

  Example: λ² - 5λ + 6 = 0
  a=1, b=-5, c=6

  discriminant = 25 - 24 = 1
  
  x = (5 + 1) / 2 = 3
  y = (5 - 1) / 2 = 2

  In eigenvalue context: a=1 always, so simplifies to:

  λ = (-b ± √(b² - 4c)) / 2
