# Linear Transformations — Session Intro

## Welcome

Transformations are required when moving space elements, but not just any transformation will do if the function also needs to consider the algebra of the space. You can think of **linear algebra as the study of linear transformations**.

Matrix multiplication and other matrix-based operations help represent linear transformations. In an attempt to explain a linear transformation, the original definition of matrix multiplication was developed. This implies that the study of linear transformations should follow if an entire algebraic system is to be built on matrices — similar to those defined on real numbers.

In this session, we will build upon the basics of vectors and matrices and learn linear transformations and linear equations.

---

## Why This Matters

**Eigenvalues and eigenvectors** are two of the fundamental concepts in linear algebra. Many problems — from machine learning to quantum computing — can be solved by determining the eigenvalues and eigenvectors of a matrix.

When dealing with a large amount of data, we frequently want to alter our data to reduce the number of features while retaining as much **variance** (the variation between samples) as possible.

Methods like **PCA (Principal Component Analysis)** and **SVD (Singular Value Decomposition)** cannot be fully understood without first understanding eigenvectors and eigenvalues — which this session covers.
