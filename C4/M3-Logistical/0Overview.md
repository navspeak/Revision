# M3 — Logistic Regression

Logistic Regression is the entry point to classification — the other half of supervised learning. Despite the name it is a **classifier**, not a regressor. Concepts learned here (sigmoid, log-loss, confusion matrix) carry into every classification model that follows.

---

| 4 | Metrics | Accuracy shortcomings, confusion matrix, precision, recall, F1 |
