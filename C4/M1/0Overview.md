# C4 — Foundations of Machine Learning

Machine learning drives modern AI — from autocomplete to healthcare. This course covers classical ML end-to-end, which remains foundational even in the age of LLMs.

---

## Course Modules

| Module | Topic | Key Ideas |
|--------|-------|-----------|
| M1 | Introduction to ML | Paradigms, AI vs ML vs DS, challenges |
| M2 | Linear Regression | Continuous prediction, coefficients, evaluation |
| M3 | Logistic Regression | Classification, decision boundaries, probabilities |
| M4 | Regularisation & Hyperparameter Tuning | Lasso, Ridge, cross-validation |
| M5 | Decision Trees | Splitting criteria, overfitting, pruning |
| M6 | Ensemble Methods | Bagging, boosting, robustness |
| M7 | K-Means Clustering | Cluster formation, distance metrics, choosing k |

---

## Prerequisites

- Algebra and probability
- Python: NumPy, Pandas, Matplotlib, Seaborn
- EDA, data preprocessing, inferential statistics

---

## Learning Outcomes

- Explain core principles of fundamental ML models
- Apply regression, classification, clustering to real data
- Improve models via regularisation, tuning, ensembles
- Evaluate results and understand each method's limits
- Recognise why classical ML still matters in the LLM era
